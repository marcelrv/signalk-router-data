How to Use This Data in Marine Apps

Standard GRIB2 surface currents & XTide harmonics work across most chartplotters and weather routers

OpenCPN GRIB2 Harmonic

  1. Forecast Currents (GRIB2): Download a .grb2 file from any Forecast dataset. In OpenCPN, enable the built-in GRIB plugin, click the GRIB toolbar icon → Open File → select the downloaded file, and turn on the Current overlay in GRIB Settings.
  2. Harmonic Stations: Download both the HARMONICS_* data file and its matching .IDX file into the same folder, then add the .IDX file under Options → Charts → Tides & Currents → Add Dataset.

qtVlm GRIB2

  1. Download a regional .grb2 file and open it via GRIB → Open GRIB (or load it as a secondary Currents GRIB alongside your wind forecast).
  2. qtVlm displays current vectors and automatically includes surface currents in weather-routing isochrones.

XyGrib GRIB2

  1. Open the downloaded .grb2 via File → Open.
  2. Enable Weather Map → Currents to inspect current speed/direction arrows and step through the forecast timeline.

LuckGrib (macOS / iOS) GRIB2

  1. Download the .grb2 file and open or AirDrop it into LuckGrib.
  2. Enable the Currents display layer to animate surface current vectors alongside wind/pressure models.

Expedition / Adrena GRIB2

  1. Import the downloaded .grb2 through the standard GRIB2 current file loader to use high-resolution regional currents in tactical and race routing.

Signal K GRIB2 UTCEF Harmonic Routing DB

  1. Tidal & Currents: Install signalk-tidal-currents and use its built-in Catalog Browser for automatic downloads and scheduled forecast refreshes.
  2. Waterway Routing: Install signalk-routeiq and open its Data Manager to download and update routing databases automatically.
